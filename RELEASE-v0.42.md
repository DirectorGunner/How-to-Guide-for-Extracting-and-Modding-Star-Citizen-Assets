\# SC Zero to Hero Installer v0.42



> First public release of the \*\*DirectorGunner\*\* single-file Windows installer for the Star Citizen community asset workflow.



\---



\## Download



Download the installer from the \*\*Assets\*\* section below:



\*\*`Launch-SC-Zero-to-Hero-Setup-v0.42.cmd`\*\*



\---



\## Highlights



\- Single-file Windows installer experience

\- Sets up the Star Citizen asset workflow workspace

\- Builds and configures \*\*StarBreaker\*\*

\- Links and enables the \*\*StarBreaker Blender add-on\*\*

\- Creates the \*\*VS Code workspace\*\*

\- Activates the shared \*\*`scdev` Python venv\*\*

\- Includes polished \*\*intro\*\* and \*\*success celebration\*\* screens

\- Exports and opens the \*\*Aurora MR\*\* example workflow



\---



\## What this release is for



This release is intended to make it dramatically easier to go from:



\*\*fresh machine → working Star Citizen asset workflow\*\*



with less manual setup, less guesswork, and a more guided developer experience.



\---



\## Before running



> Right-click the downloaded `.cmd`, open \*\*Properties\*\*, click \*\*Unblock\*\* if that option appears, then run it as \*\*Administrator\*\*.



> Smart App Control may still block unsigned developer tooling. Administrator mode does \*\*not\*\* bypass Smart App Control.



\---



\## Blender note



If the model opens but looks untextured, switch the viewport shading to:



\- \*\*Material Preview\*\*, or

\- \*\*Rendered\*\*



using the viewport shading icons in the top-right corner of the Blender 3D View.
